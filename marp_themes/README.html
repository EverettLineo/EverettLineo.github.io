Marp 主题集合

这是一个精选的 Marp 主题集合，用于使用 Markdown 创建精美的演示文稿。这些主题来自多个开源项目，并经过修改以满足个人需求。

This document and license information are created BY LLM (ChatGPT etc.) based on the original content written in Chinese.

Marp 是一个强大的工具，可以让你使用 Markdown 语法创建演示文稿，告别传统 PPT 编辑器的繁琐操作。

🚀 使用方法

在 VS Code 中使用

  1. 安装 Marp 扩展

    • 在 VS Code 扩展市场搜索并安装 Marp for VS Code

  2. 配置主题路径

    • 打开 VS Code 设置（Ctrl + , 或 Cmd + ,）
    • 搜索 “Marp: Themes” 或 “markdown.marp.themes”，配置：

    URL 模板：
    https://everettlineo.github.io/marp_themes/css/<name>.css（将 <name>.css 替换为下方列出的文件名）：

📖 字体说明

部分主题使用了特定字体以获得最佳显示效果：

Awesome Marp 系列

  • 正文字体：Latin Modern Math、方正宋刻本秀楷简体（未安装时使用 Calibri 和 楷体）
  • 标题字体：Optima LT Medium、方正苏新诗柳楷简体（未安装时使用 Arial 和 黑体）
  • 脚注字体：Charm、叶根友毛笔行书修正版（未安装时使用 Calibri 和 楷体）
  • 代码字体：Fira Code、霞鹜文楷等宽（未安装时使用 Consolas 和 华文中宋）

beam 主题

  • 推荐下载 Computer Modern Unicode 字体家族以获得最佳效果

🎨 主题定制

大多数主题支持通过修改 CSS 变量来调整颜色、字体等样式。你可以：

  1. 直接编辑 CSS 文件中的 :root 变量
  2. 在 Markdown 文件中使用内联样式覆盖
  3. 参考各主题的原始仓库了解更多定制选项
